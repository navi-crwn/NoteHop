HOP · Notas e documentos criptografados

Trancado no seu navegador, compartilhado em segundos

O NoteHop criptografa suas notas localmente com AES-256-GCM antes de saírem do seu dispositivo. A chave reside no fragmento da URL (#), impedindo o servidor de ler seu conteúdo. Links curtos limpos em n.hel.ink, código aberto (MIT).

O que o NoteHop faz

  • Criptografia no cliente AES-256-GCM

    Seu navegador criptografa o texto antes de salvá-lo. A chave de decodificação viaja no fragmento do link (#) e nunca é enviada ao servidor.

  • Servidor de conhecimento zero

    O servidor armazena apenas dados cifrados. Nem mesmo operadores do sistema ou backups conseguem ler seus textos privados.

  • Autodestruição e queima após leitura

    Notas podem se autoexcluir após a primeira abertura ou expirar automaticamente em 10 minutos, 1 hora, 1 dia ou 30 dias.

  • Permissões granulares por link

    Emita links diferentes para a mesma nota: proprietário, somente leitura, edição, apenas resposta ou apenas marcação de tarefas.

  • Colaboração ao vivo em tempo real

    Trabalhem juntos em tempo real via relays WebSocket, mantendo o sigilo de ponta a ponta entre todos os participantes.

  • Formatos ricos de nota

    Textos em Markdown, listas de tarefas, enquetes, formulários, notas de código e páginas web isoladas.

  • Um único login: HOP ID

    Faça login com a conta unificada HOP ID em toda a família HOP ou utilize o NoteHop anonimamente como visitante.

  • Binário único em Go para auto-hospedagem

    Executável Go de ~16 MB com SQLite integrado, sem dependências externas de runtime e de instalação rápida.

Auto-hospedagem

O NoteHop pode ser hospedado por você. Compile e execute o binário único em segundos:

git clone https://github.com/navi-crwn/NoteHop.git
cd NoteHop
go build -o notehop ./cmd/notehop
./notehop

Requisitos

Go 1.22+ e SQLite. Instruções completas de início rápido, Docker e testes no README do GitHub.

Configuração de login

O login utiliza o SSO HOP ID. Configure NOTEHOP_SSO_HUB_URL e NOTEHOP_SSO_SECRET no seu ambiente antes de entrar, ou opere em modo independente.

Banco de Dados e Armazenamento

O NoteHop utiliza SQLite integrado com armazenamento local. Faça backups durante a execução com notehop backup.

Os modos independente e SSO são totalmente suportados em instalações próprias.

Perguntas frequentes

O servidor ou provedor consegue ler minhas notas?

Não. A criptografia ocorre inteiramente no seu navegador via Web Crypto AES-256-GCM. A chave fica no hash da URL (#) e nunca é enviada ao servidor.

O que acontece se eu perder o link da minha nota?

Por ser de conhecimento zero e sem chaves mestras ou portas dos fundos, perder o link significa que a nota não pode ser recuperada por ninguém.

Posso hospedar o NoteHop no meu servidor?

Sim. O NoteHop compila em um único executável Go sem dependências externas de runtime. Veja o README do repositório.

Onde posso relatar falhas ou vulnerabilidades?

Abra uma issue no GitHub ou escreva para security@hel.ink para divulgação responsável.
