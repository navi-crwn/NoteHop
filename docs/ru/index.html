HOP · Шифрованные заметки и документы

Зашифровано в вашем браузере, отправлено за секунды

NoteHop шифрует ваши заметки локально по алгоритму AES-256-GCM до отправки в сеть. Ключ хранится исключительно во фрагменте URL (#), поэтому сервер физически не может прочитать текст. Короткие ссылки на n.hel.ink, открытый исходный код (MIT).

Что умеет NoteHop

  • Клиентское шифрование AES-256-GCM

    Браузер шифрует текст перед отправкой. Ключ находится в хеш-фрагменте ссылки (#) и никогда не передается на сервер.

  • Архитектура с нулевым разглашением

    Сервер хранит только зашифрованные блоки. Даже системные операторы или дампы базы данных не могут прочитать ваши записи.

  • Самоуничтожение и удаление после чтения

    Заметки могут исчезать сразу после первого прочтения или автоматически удаляться через 10 минут, 1 час, 1 день или 30 дней.

  • Раздельные права для каждой ссылки

    Создавайте разные ссылки для одной заметки: владелец, только чтение, редактирование, только ответы или чек-листы.

  • Совместное редактирование в реальном времени

    Работайте одновременно через WebSocket-реле с полным сохранением сквозного шифрования между всеми участниками.

  • Разнообразие форматов заметок

    Markdown-заметки, интерактивные списки задач, опросы, формы, фрагменты кода и изолированные веб-страницы.

  • Единый аккаунт для всех сервисов: HOP ID

    Быстрый вход через систему единого входа HOP ID для всех приложений экосистемы, либо анонимный гостевой режим.

  • Единый бинарный файл на Go для хостинга

    Легковесный исполняемый файл ~16 МБ со встроенной SQLite, без внешних зависимостей и сложностей развертывания.

Частые вопросы

Может ли сервер или хостинг прочитать мои заметки?

Нет. Шифрование происходит целиком в браузере через Web Crypto AES-256-GCM. Секретный ключ остается в хеше ссылки (#) и не отправляется на сервер.

Что делать, если я потеряю ссылку на заметку?

Поскольку NoteHop построен на принципе нулевого разглашения и не имеет бэкдоров, потеря ссылки делает восстановление заметки невозможным.

Могу ли я запустить NoteHop на своем сервере?

Да. NoteHop компилируется в единственный исполняемый файл без внешних зависимостей. Инструкции приведены в README репозитория.

Куда сообщать об уязвимостях или ошибках?

Создайте Issue на GitHub или отправьте письмо на security@hel.ink для ответственного раскрытия информации.
