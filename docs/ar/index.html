HOP · ملاحظات ووثائق مشفرة

مشفرة في متصفحك، ومشتركة في ثوانٍ

يقوم NoteHop بتشفير ملاحظتك محلياً بتقنية AES-256-GCM قبل أن تغادر جهازك. مفتاح فك التشفير يبقى في تجزئة الرابط (#)، لذا يعجز الخادم تماماً عن قراءة بياناتك. روابط قصيرة نظيفة على n.hel.ink، مفتوح المصدر (MIT).

جرب NoteHop عرض الكود

الروابط المباشرة في هذه الصفحة تشير إلى المواقع العامة لعائلة HOP.

ما يقدمه NoteHop

  • تشفير AES-256-GCM في المتصفح

    يقوم متصفحك بقفل المحتوى قبل إرساله. يسافر مفتاح التشفير ضمن وسم الرابط (#) ولا يُرسل أبداً إلى الخادم.

  • خادم بمعرفة معدومة (Zero-knowledge)

    لا يخزن الخادم سوى نصوص مشفرة غير قابلة للقراءة. حتى مدراء النظام أو النسخ الاحتياطية لا يمكنهم فك تشفير ملاحظاتك.

  • تدمير ذاتي وحرق بعد القراءة

    تُحذف الملاحظات فور قراءتها لمرة واحدة، أو تنتهي صلاحيتها بعد 10 دقائق أو ساعة أو يوم أو شهر.

  • صلاحيات مخصصة لكل رابط

    أصدر روابط مختلفة للملاحظة الواحدة: مالك، قراءة فقط، قابل للتحرير، ردود فقط، أو تأشير المهام فقط.

  • تعاون حي ومباشر

    اكتبوا معاً في الوقت الفعلي عبر وسيط WebSocket مع الحفاظ الكامل على التشفير بين الأطراف.

  • أنواع ملاحظات متعددة

    نصوص Markdown، وقوائم مهام تفاعلية، واستطلاعات، ونماذج، وملاحظات برمجية، وملاحظات ويب معزولة.

  • تسجيل دخول موحد: HOP ID

    سجل الدخول بسهولة عبر حساب HOP ID الموحد عبر جميع تطبيقات HOP، أو استخدم NoteHop كزائر مجهول.

  • ملف تنفيذي واحد بلغة Go

    ملف تنفيذي مستقل وخفيف بحجم ~16 ميغابايت مع SQLite مدمج، ولا يتطلب أي حزم خارجية.

استضافة ذاتية

يمكن استضافة NoteHop ذاتياً. قم ببناء وتشغيل الملف في ثوانٍ:

git clone https://github.com/navi-crwn/NoteHop.git
cd NoteHop
go build -o notehop ./cmd/notehop
./notehop

المتطلبات

Go 1.22+ و SQLite. راجع ملف README على GitHub للاطلاع على تعليمات البدء السريع وDocker والاختبارات.

إعداد تسجيل الدخول

يستخدم تسجيل الدخول نظام HOP ID. قم بضبط NOTEHOP_SSO_HUB_URL و NOTEHOP_SSO_SECRET قبل الدخول، أو اعمل في وضع مستقل.

قاعدة البيانات والتخزين

يعتمد NoteHop افتراضياً على قاعدة بيانات SQLite مدمجة وتخزين محلي. يمكن أخذ نسخ احتياطية أثناء التشغيل عبر notehop backup.

الوضع المستقل ووضع الدخول الموحد مدعومان بالكامل في التثبيت الذاتي.

الأسئلة الشائعة

هل يستطيع الخادم أو مزود الاستضافة قراءة ملاحظاتي؟

كلا. يتم التشفير بالكامل داخل متصفحك عبر واجهة Web Crypto AES-256-GCM. ويبقى المفتاح في الرابط (#) دون إرساله للخادم.

ماذا يحدث إذا فقدت رابط ملاحظتي؟

نظراً لأن NoteHop مبني على مبدأ المعرفة المعدومة وبلا أبواب خلفية، فإن فقدان الرابط يعني استحالة استرجاع الملاحظة أو فك تشفيرها.

هل يمكنني استضافة NoteHop على خادمي الخاص؟

نعم. يترجم NoteHop إلى ملف تنفيذي مستقل بلغة Go دون أي متطلبات تشغيل خارجية. راجع دليل README في المستودع.

أين أبلغ عن المشكلات أو الثغرات الأمنية؟

يمكنك فتح مشكلة في GitHub أو مراسلتنا عبر security@hel.ink للإبلاغ المسؤول عن الثغرات.
