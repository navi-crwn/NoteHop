HOP · Verschlüsselte Notizen & Dokumente

Im Browser verschlossen, in Sekunden geteilt

NoteHop verschlüsselt deine Notiz standardmäßig in deinem Browser mit AES-256-GCM, bevor sie dein Gerät verlässt. Der Schlüssel liegt im URL-Fragment (#), sodass der Server eine verschlüsselte Notiz nicht lesen kann. Eine einfache Notiz, die der Server lesen kann, bekommt einen Linknamen deiner Wahl. Kurzlinks auf n.hel.ink, Open Source (MIT).

Was NoteHop kann

  • AES-256-GCM im Client

    Dein Browser verschlüsselt den Inhalt vor dem Speichern. Der Schlüssel reist im Link-Fragment (#) und wird nie an den Server gesendet.

  • Ein Server, der verschlüsselte Notizen nicht lesen kann

    Bei einer verschlüsselten Notiz speichert der Server nur den Geheimtext, sodass Betreiber und Datenbank-Dumps weder Titel noch Text lesen können. Einfache Notizen werden als Klartext gespeichert und sind als einfach gekennzeichnet.

  • Selbstzerstörung & Löschen nach dem Lesen

    Notizen können sich direkt nach dem ersten Lesen löschen oder automatisch nach 10 Minuten, 1 Stunde, 1 Tag oder 30 Tagen ablaufen.

  • Fein abgestufte Rechte pro Link

    Erstelle für dieselbe Notiz verschiedene Links: Inhaber, nur lesen, schreiben, nur antworten oder nur abhaken bei Checklisten.

  • Gemeinsames Bearbeiten live

    Schreibt gemeinsam in Echtzeit über ein WebSocket-Relay. In einer verschlüsselten Notiz ist alles verschlüsselt, was das Relay weiterreicht.

  • Vielfältige Notizarten

    Markdown-Text, interaktive Checklisten, Umfragen, Formulare, Code-Notizen mit Syntaxfarben und Web-Notizen in einer abgeschotteten Umgebung.

  • Eine Anmeldung für alle Apps: HOP ID

    Melde dich nahtlos mit deinem einheitlichen HOP-ID-Konto in der gesamten HOP-Familie an, oder nutze NoteHop anonym als Gast.

  • Selbst hosten mit einem einzigen Go-Programm

    Ein Go-Programm von etwa 20 MB mit eingebautem SQLite, nichts weiter zu installieren, und ein Installer, der mit einem Befehl auskommt.

FAQ

Können der Server oder der Hoster meine Notizen lesen?

Eine verschlüsselte Notiz nicht. Dein Browser verschlüsselt sie vor dem Senden mit Web Crypto AES-256-GCM, und der Schlüssel bleibt im URL-Hash (#), den Browser nicht an einen Server senden. Eine einfache Notiz ist nicht verschlüsselt, der Server kann sie lesen.

Was passiert, wenn ich den Link zu meiner Notiz verliere?

Eine verschlüsselte Notiz kann niemand wiederherstellen. NoteHop hat weder einen Generalschlüssel noch eine Hintertür, der Link ist der einzige Zugang. Eine einfache Notiz lässt sich über ihren Linknamen wiederfinden.

Kann ich NoteHop auf meinem eigenen Server betreiben?

Ja. NoteHop wird zu einem einzigen eigenständigen Go-Programm ohne externe Abhängigkeiten kompiliert. Die Einrichtung steht in der README des Repositorys.

Wo melde ich Sicherheitslücken oder Fehler?

Bitte eröffne für eine Sicherheitslücke kein öffentliches Issue. Melde sie privat über GitHub: Öffne den Reiter Security des Repositorys und wähle Report a vulnerability. Details stehen in SECURITY.md.
